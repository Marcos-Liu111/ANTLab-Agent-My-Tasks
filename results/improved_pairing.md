## 3. 变体检查（不调用模型，`tools/variant_check.py`）

- P1 打乱输入顺序 100 次，分档输出序列不变；
- P2 ID 重映射 P→Q 后选择结构不变；

**结论**：improve() 按段落内容分档，不依赖输入位置或 ID 生成结果——
"事实没有变化而结果变化时解释原因"的反面证据：方法本身对顺序/ID 不变，
baseline 与 improved 的差异来自**呈现顺序改变影响模型判断**，而非方法读了位置。
